# 联产品加工资料约定

所有实物以公斤计，金额以元计。单工序投入量等于产出与工序损失之和。采购量没有第二份入库记录；分切后的库存须扣除继续加工和销售，销售退回按负流出计。跨批混料保留各投入阶段。损失记录中的 lot_id 仅用于说明损耗原属物，不构成再扣同批实物的第二条出库。金额保留十进制精度。

## 数据表

### `lots`

批次代表特定工序阶段的实物，返工后另建阶段批次。采购批次期初量由首个投入量确认；各阶段未流出量是库存。

| 字段 | 解析类型 |
| --- | --- |
| `id` | `text` |
| `product` | `text` |
| `period` | `text` |
| `unit` | `text` |

### `operations`

加工实际操作，sequence 为本地工序顺序；同一原料名可能多次出现，但阶段编号不混淆。

| 字段 | 解析类型 |
| --- | --- |
| `id` | `text` |
| `day` | `date` |
| `kind` | `text` |
| `sequence` | `int` |

### `flows`

物料为正数量，方向为 input、output、loss；loss 是工序损失，不再作为额外投入扣第二遍。

| 字段 | 解析类型 |
| --- | --- |
| `id` | `text` |
| `operation_id` | `text` |
| `lot_id` | `text` |
| `direction` | `text` |
| `quantity` | `number` |

### `costs`

成本只挂批次或工序之一；是否可避免是业务已批准的属性，不等同于财务分摊方式。

| 字段 | 解析类型 |
| --- | --- |
| `id` | `text` |
| `lot_id` | `text?` |
| `operation_id` | `text?` |
| `amount` | `money` |
| `kind` | `text` |
| `avoidable` | `bool` |

### `sales`

销售金额为不含税净额，负数退回指向原销售，退回实物进入原阶段库存；未售库存不是当期损耗。

| 字段 | 解析类型 |
| --- | --- |
| `id` | `text` |
| `lot_id` | `text` |
| `day` | `date` |
| `quantity` | `number` |
| `amount` | `money` |
| `return_of` | `text?` |

## 文件和数值语义

空单元格只在带问号的类型中表示缺失；零和空值不同。金额由十进制定点字符串保存，浮点数仅用于探索性统计。所有数据均为本地生成的虚构经营记录，不对应真实公司、客户或住址。数值剖面只反映观察数据，不能代替总体推断。

研究备注的参数为业务自由对象，不代表已执行了任何统计模型。原始表与已有视图可单独查询。
