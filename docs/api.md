# 资料服务接口

服务只在本机提供 JSON，响应编码为 UTF-8。查询接口不修改资料。

| 方法和路径 | 当前行为 |
| --- | --- |
| `GET /health` | 数据指纹和存活状态 |
| `GET /tables` | 表、字段类型和记录数 |
| `GET /tables/{name}?offset=0&limit=50` | 原始资料分页；偏移非负，每页一至五百行 |
| `GET /view` | 当前领域经营资料摘要 |
| `GET /profiles` | 数值字段的观察数、缺失数、中位数及绝对中位差 |
| `GET /bridge?basis=weight&from=2026-09&to=2026-10` | 收益桥分析：计量闭合、成本流转、三种收益视图、毛利变动分解与分摊选择敏感性；参数可省略，`basis` 为毛利桥参考口径（`weight` 或 `nrv`） |
| `GET /bridge/lots/{lot_id}` | 单批次核对视图：闭合、两口径成本流转与分摊毛利，附物料与金额证据 |
| `POST /cases` | 保存研究备注和当前完整资料副本；返回新记录 |
| `GET /cases` | 研究记录索引 |
| `GET /cases/{id}` | 校验完整性并回读记录 |

创建研究备注的字段为 `label`、`options`、`notes` 和 `analysis`，分别是名称、参数对象、说明文字与要嵌入的分析快照。名称一至一百二十字，后三项可省略。`analysis` 目前仅支持 `"bridge"`，会把当前收益桥分析结果随资料副本一并保存。不接受其他字段，不允许覆盖旧记录。记录 ID 由服务生成。资料指纹由原始数据和结构共同形成，不表示计算结果的统计可信度。

源表未找到或记录 ID 无效返回 404；字段或分页无效返回 400。默认监听 127.0.0.1:8080。服务当前提供资料浏览、数值探索和研究备注，不将保存备注视为已经完成经营分析。
